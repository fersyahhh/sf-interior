- Primary: #0057ff (Bright Blue)
- Surface: #f9f9f9 (Light)

## 📞 Support

### Common Tasks

**Update Services**
- Edit `src/constants/index.ts`
- Add/remove items from `SERVICES` array

**Update Portfolio**
- Edit `src/constants/index.ts`
- Add/remove items from `PORTFOLIO_PROJECTS` array

**Change Colors**
- Edit hex values in `src/index.css`
- Update `tailwind.config.ts` if needed

**Modify Animations**
- Edit keyframes in `src/index.css`
- Adjust delays in component `style` attributes

**Add New Section**
- Create feature folder in `src/features/`
- Create component file
- Import in `src/App.tsx`
- Add navigation link if needed
